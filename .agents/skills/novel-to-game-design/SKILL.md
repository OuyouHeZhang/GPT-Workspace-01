# NovelToGame Design

读[上游游戏设计入口](references/upstream/GUIDE.md)，再选[概念](references/upstream/references/concept-method.md)、[世界设计](references/upstream/references/world-design-method.md)、[互动叙事](references/upstream/references/narrative-design-method.md)和[视听方向](references/upstream/references/art-direction-method.md)。以有权使用的来源或用户的原创设定为依据。为每个关键选择写清依据、风险、立即反馈和后文兑现点。
在 Codex 中使用 `novel-to-game-design` 调用本项。通用玩法设计可继续调用 `game-design`。

[固定版本来源](https://github.com/zenstory-ai/novel-to-game/tree/48328cd756cd400e617e97dc3bd5c4b42cda3f72/skills/game-design)。
