# Vertical Slice

读[完整试玩样段指南](references/upstream/GUIDE.md)和[原型报告模板](references/upstream/prototype-report.md)。选择最能代表核心体验的一段，覆盖进入、行动、判断、挑战、反馈与收束。先写出最重要的体验假设和能观察到的行为，再按正常入口试玩。保留证据与改动优先级，根据项目阶段控制美术和工程范围。
