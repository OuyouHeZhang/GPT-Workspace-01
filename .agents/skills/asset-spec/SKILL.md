# Asset Spec

读 [Codex 资产规格流程](references/upstream/GUIDE.md)，需要更完整清单和提示词细节时读 [Game Studios 原始说明](references/upstream/original-asset-spec.md)。
沿用已有美术设定，写清资产用途、展示尺寸、相机、透明边缘、动画动作、导出格式、命名与验收图。技术结构与教材事实来自已核实的资料或用户提供的源资产。制作阶段按素材类别选 `sprite-pipeline` 或 `assetelier`。
